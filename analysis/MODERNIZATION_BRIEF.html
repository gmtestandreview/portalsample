The portal is structurally sound with a modern stack, but targeted debt creates migration risk: broad any-typed wizard contracts, repeated token acquisition logic across 26 files, one high-priority backend IDOR confirmation blocker, and no unit tests inside the core source tree.

1. Objective

Modernize the existing React 18 and TypeScript SPA incrementally, preserving current architecture while eliminating concentrated security and maintainability risks. Deliver a type-safe, test-backed, single-build-system codebase that a new engineering team can operate without relying on undocumented institutional knowledge.

Primary Debt Concentrations

  • Wizard engine contract uses broad index signatures that remove compile-time guarantees.
  • Token acquisition and client wiring duplicated across 26 call sites.
  • Open security items remain, including backend IDOR verification (P0 gate).
  • No unit-test safety net in ClientApp/src despite high business-rule density.

Already Closed in Live Codebase

  • Auth bypass variables and dev bypass path removed.
  • Trusted Types hardening completed (createHTML and createScript).
  • noopener and open-redirect protections added.
  • PII telemetry scrubbing completed.
