## Primary Button

The primary button is used for the main action on a page or dialog. It draws attention and encourages user interaction.

### Use Cases

- **Main form submissions** — "Submit", "Save", "Continue"
- **Primary actions** — "Create", "Download", "Publish"  
- **Call-to-action buttons** — Desktop and mobile CTAs

### Accessibility

- Full keyboard support (Tab, Enter, Space)
- Proper ARIA attributes for disabled state
- High contrast ratio (WCAG AA compliant)
- Screen reader announcements for disabled state

### Light Mode (Default)


## Design System Integration

The Primary Button follows the NMI design system specifications:

- **Light Mode**: Blue background (#0066CC) with white text
- **Dark Mode**: Dark blue background (#003D99) with white text
- **Disabled**: Gray background (#E0E0E0) with gray text
- **Hover**: Darkened background color on hover
- **Focus**: Visible focus ring for keyboard navigation

## Best Practices

✅ Use for primary/main actions only  
✅ Use clear, action-oriented labels  
✅ Ensure sufficient contrast ratio  
✅ Provide visual feedback on hover/focus  
✅ Test with keyboard navigation  

❌ Don't use multiple primary buttons in one section  
❌ Don't use for secondary or tertiary actions  
❌ Don't disable without explanation  
❌ Don't use overly long button text
