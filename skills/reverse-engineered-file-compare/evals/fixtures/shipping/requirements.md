# Shipping fee requirements

This is a synthetic evaluation fixture. Treat these rules as the authoritative
requirements for this scenario.

- R1: Standard shipping costs 5 and express shipping costs 15 when the subtotal
  is below 100.
- R2: Shipping is free for either delivery method when the subtotal is at
  least 100. This rule was added after the historical original.

The files are intentionally small. No runtime test suite or approved performance
target is supplied.
