## Source-use rules

- Use the bundled operational references for normal execution.
- Use an original checklist only when detailed rationale, examples, or
  traceability are required.
- If a task requires exact framework wording, edition-specific interpretation,
  or current regulatory/policy information, consult the relevant authoritative
  source if it is available.
- Do not fabricate content from a source that is unavailable.
- Do not treat older static source material as proof of current Australian
  Government policy or legislation.
